# BC Brain Wishlist — รายการข้อมูลที่ต้องการเพิ่มเข้าสมอง (`d:\bcbrain`) และ Prompt สำเร็จรูป

เป้าหมาย: เก็บรวบรวมช่องว่างความรู้และสิ่งที่ต้องการปรับปรุงฝั่งสมอง **`d:\bcbrain`** (`https://brain.bcsmethai.com/mcp`) ที่พบจาก **สายเข้าจริงของลูกค้า** พร้อม **Prompt สำเร็จรูป** เพื่อให้ลุงจืดคัดลอกไปสั่ง AI ใน `d:\bcbrain` ปรับปรุงได้ทันที

## วิธีใช้งานไฟล์นี้
- **ระบบนี้ใช้สมอง `d:\bcbrain`** และห้ามแก้ไขไฟล์ใน `d:\bcbrain` เอง — ทุกครั้งที่ต้องการเพิ่มข้อมูล ปรับคำค้น/คำพ้อง หรือปรับปรุงฝั่งสมอง ให้เขียนรายการและ **Prompt สำเร็จรูป** ไว้ในไฟล์นี้เพื่อให้ลุงจืดนำไปให้ `d:\bcbrain` ดำเนินการ
- **รอบพัฒนาตัวเองอัตโนมัติ (ทุก 4 ชม.)** จะตรวจสอบสายเข้าใหม่ที่ยังไม่เคยวินิจฉัย หากพบคำถามจริงที่ลูกค้าถามแล้วติด `Abstain` / `BRAIN-NEARBY-FALLBACK` หรือข้อมูลใน **BC Brain** ยังไม่ชัดพอ จะนำมาเพิ่มต่อท้ายในหมวดที่ 1 พร้อมอัปเดต **Prompt สำเร็จรูปสำหรับ `d:\bcbrain`** ในหมวดที่ 4 (ปิดบังเบอร์โทรและชื่อส่วนตัวลูกค้า 100%)
- เมื่อลุงจืดนำ Prompt ไปให้ `d:\bcbrain` ปรับปรุงเรียบร้อยแล้ว ในรอบถัดไป (หรือเมื่อสั่งตรวจ) ระบบจะตรวจสอบความพร้อมจากสมองและย้ายรายการที่เสร็จแล้วจาก `[ ]` เป็น `[x]` ไปไว้ในหัวข้อ **3. เพิ่มเข้าสมองเรียบร้อยแล้ว (Archive)**
- **อย่าใส่เบอร์โทรจริง ชื่อส่วนตัวลูกค้า อีเมล หรือ Public IP** ลงในไฟล์นี้
