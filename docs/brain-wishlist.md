# BC Brain Wishlist — รายการข้อมูลที่ต้องการเพิ่มเข้าสมองและสิ่งที่ขอจากลุงจืด

เป้าหมาย: เก็บรวบรวมช่องว่างความรู้ที่พบจาก **สายเข้าจริงของลูกค้า** เพื่อให้ J.A.R.V.I.S ตอบคำถามได้ถูกต้อง ครบถ้วน และรวดเร็วมากขึ้น

## วิธีใช้งานไฟล์นี้
- **รอบพัฒนาตัวเองอัตโนมัติ (ทุก 4 ชม.)** จะตรวจสอบสายเข้าใหม่ที่ยังไม่เคยวินิจฉัย หากพบคำถามจริงที่ลูกค้าถามแล้วติด `Abstain` / `BRAIN-NEARBY-FALLBACK` หรือข้อมูลใน **BC Brain** ยังไม่ชัดพอ จะนำมาเพิ่มต่อท้ายในหมวดที่ 1 พร้อมแนะนำ `slug` (ปิดบังเบอร์โทรและชื่อส่วนตัวลูกค้า 100%)
- เมื่อลุงจืดเพิ่มข้อมูลลง **BC Brain** แล้ว ในรอบถัดไป (หรือเมื่อสั่งตรวจ) ระบบจะตรวจสอบความพร้อมจากสมองและย้ายรายการที่เสร็จแล้วจาก `[ ]` เป็น `[x]` ไปไว้ในหัวข้อ **3. เพิ่มเข้าสมองเรียบร้อยแล้ว (Archive)**
- **อย่าใส่เบอร์โทรจริง ชื่อส่วนตัวลูกค้า อีเมล หรือ Public IP** ลงในไฟล์นี้

## 1. รายการข้อมูลที่ต้องการเพิ่มเข้า BC Brain (สมอง)

- [ ] **รูปแบบการใช้งาน Cloud / On-Premise และหลายสาขาภายใต้นิติบุคคลเดียวกัน** (slug แนะนำ: `sales-cloud-multi-branch`)
  - **พบจากสาย**: `2026-11-24` (`1795521035658-dasqp`)
  - **คำถามจริงของลูกค้า**: "ถ้ามีสาขาอีกที่หนึ่ง เป็นนิติบุคคลเดียวกัน อยู่คนละที่ จะมีปัญหาเรื่องคลาวด์ไหม BC อยู่บนคลาวด์หรือเปล่า และ Transaction/ยอดขายแต่ละสาขาแยกกันหรือรวมกันยังไง"
  - **สิ่งที่มีในสมองปัจจุบัน**: `howto-setup-branch-dept` (เมนู `1007`, `1004`), `sales-overview` และ `sales-faq-before-buy` (ระบุเฉพาะ `Private Cloud` ในรุ่น Enterprise และ POS ออฟไลน์ซิงก์)
  - **ข้อมูลที่อยากให้ลุงจืดเพิ่มในสมอง**: อธิบายให้ชัดเจนว่าทุกรุ่น (`Starter`, `Standard`, `Professional`, `Enterprise`) ใช้งานผ่านเว็บ/คลาวด์ หรือติดตั้งบนเซิร์ฟเวอร์เองได้อย่างไร และเมื่อมีหลายสาขาอยู่คนละสถานที่ภายใต้นิติบุคคลเดียวกัน ข้อมูลเชื่อมกันแบบเรียลไทม์และแยก/รวม Transaction อย่างไร

- [ ] **รายงานสรุปยอดขายรายวันแยกตามสาขา (ระบุรหัสเมนู 4 หลักและวิธีกรอง)** (slug แนะนำ: `rpt-sales-by-branch`)
  - **พบจากสาย**: `2026-11-24` (`1795521035658-dasqp`)
  - **คำถามจริงของลูกค้า**: "เวลาออกบิลให้ลูกค้าแล้ว อยากสรุปเป็นยอดขายว่าวันนี้ขายได้เท่าไหร่ สาขาไหนขายได้เท่าไหร่ ดูรายงานตัวไหน"
  - **สิ่งที่มีในสมองปัจจุบัน**: `howto-setup-branch-dept` (ระบุว่าแยกยอดขายและกำไรขาดทุนตามสาขาได้), `rpt-sale-so`, เมนู `4050`–`4053` (สรุปยอดขายตามวันที่/พนักงานขาย), และเมนู `9058` / `9063` (งบทดลอง/งบกำไรขาดทุนแยกสาขา)
  - **ข้อมูลที่อยากให้ลุงจืดเพิ่มในสมอง**: ระบุรหัสเมนู 4 หลักของรายงานขาย (`40xx`) ที่กรองหรือจัดกลุ่มยอดขายรายวันแยกตามสาขาได้ตรงๆ พร้อมขั้นตอนเลือกเงื่อนไขสาขาบนหน้าจอรายงาน

- [ ] **การแจ้งเตือนอัตโนมัติเมื่อถึงกำหนดเก็บเงินลูกหนี้/จ่ายเงินเจ้าหนี้ (หน้าจอ vs Push / LINE / Email)** (slug แนะนำ: `sys-due-date-alerts`)
  - **พบจากสาย**: `2026-11-24` (`1795521035658-dasqp`)
  - **คำถามจริงของลูกค้า**: "ตอนนี้ BC พัฒนาไปถึงขั้นที่มีแจ้งเตือนว่าถึงดิวเก็บเงินลูกค้ารายนี้หรือจ่ายเงินเจ้าหนี้รายนี้แล้วหรือยัง"
  - **สิ่งที่มีในสมองปัจจุบัน**: `sys-companybrain-briefing` (เมนู `1001` ศูนย์แจ้งเตือนยามเช้า 6 การ์ด: ลูกหนี้เกินกำหนดชำระ, เจ้าหนี้ครบกำหนดใน 7 วัน, เช็คถึงกำหนดใน 7 วัน), `term-ar-ap-aging` และเมนู `5036`–`5038`
  - **ข้อมูลที่อยากให้ลุงจืดเพิ่มในสมอง**: ระบุให้ชัดว่านอกจากหน้าจอศูนย์แจ้งเตือนยามเช้า (`1001`) ในโปรแกรมแล้ว ปัจจุบันมีการส่งแจ้งเตือนอัตโนมัติออกภายนอกผ่าน LINE / Email / Push notification หรือยัง และตั้งค่าอย่างไร

- [ ] **ระบบขายผ่อนชำระ/เช่าซื้อฝั่งผู้ขาย และวิธีบันทึกส่วนลดรับ/เศษสตางค์ตอนจ่ายชำระเจ้าหนี้** (slug แนะนำ: `faq-installment-and-ap-rounding`)
  - **พบจากสาย**: `2026-11-24` (`1795487640213-59o0g`, `1795484141570-qlczo`)
  - **คำถามจริงของลูกค้า**: (ก) สอบถามระบบเช่าซื้อ/ขายผ่อนให้ลูกค้า (ข) ตอนจ่ายชำระหนี้เจ้าหนี้แล้วมีส่วนลดรับหรือเศษสตางค์ ต้องกรอกช่องไหนเพื่อไม่ให้ยอดค้างไม่ตรงบิล
  - **สิ่งที่มีในสมองปัจจุบัน**: มี `howto-asset-hire-purchase` (ฝั่งผู้เช่าซื้อรถยนต์/สินทรัพย์), `howto-ar-contract` (สัญญาลูกหนี้แบ่งงวด), และ `howto-ap-payment` / `start-coa-presets` (`ส่วนลดรับ`)
  - **ข้อมูลที่อยากให้ลุงจืดเพิ่มในสมอง**: (ก) ระบุให้ชัดว่าระบบรองรับธุรกิจขายผ่อน/เช่าซื้อให้ลูกค้ารายงวดหรือไม่ หรือใช้ฟีเจอร์สัญญาลูกหนี้แบ่งงวดแทน (ข) ขั้นตอนสั้นๆ สำหรับกรอกช่องส่วนลดรับหรือปรับยอดเศษสตางค์บนหน้าจอจ่ายชำระหนี้เจ้าหนี้
