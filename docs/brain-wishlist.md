# BC Brain Wishlist — รายการข้อมูลที่รอเติมเข้าคลังความรู้ในเครื่อง (`bcbrain/vault/`)

เป้าหมาย: เก็บรวบรวมช่องว่างความรู้ที่พบจาก **สายเข้าจริงของลูกค้า** ซึ่งยังไม่มีข้อเท็จจริงยืนยันในคลัง `bcbrain/vault/` ของโปรเจกต์นี้ เพื่อรอลุงจืดให้ข้อมูลจริงแล้วนำมาเขียนเป็นโน้ต `.md` ลงใน `bcbrain/vault/` โดยตรง (ระบบจะ Hot-Reload เข้า RAM ทันทีภายใน 3 วินาทีโดยไม่ต้องผ่าน MCP API)

## วิธีใช้งานไฟล์นี้
- **คลังความรู้ `bcbrain/vault/` รวมอยู่ในโปรเจกต์ `d:\yalecom` เป็นเนื้อเดียวกันแล้ว** — เมื่อลุงจืดให้ข้อมูลจริงในรายการใด ระบบสามารถเขียน/อัปเดตโน้ต `.md` ใน `bcbrain/vault/` ได้โดยตรงทันที (ห้ามเดาหรือแต่งเติมข้อเท็จจริงเอง)
- **รอบพัฒนาตัวเอง (สั่งรันด้วยมือตาม [dev-on-the-fly.md](dev-on-the-fly.md))** จะตรวจสอบสายเข้าใหม่ที่ยังไม่เคยวินิจฉัย หากพบคำถามจริงที่ลูกค้าถามแล้วติด `Abstain` / `BRAIN-NEARBY-FALLBACK` และยังไม่มีข้อเท็จจริงใน `bcbrain/vault/` จะเพิ่มต่อท้ายในหมวดที่ 1 พร้อม `slug` แนะนำ (ปิดบังเบอร์โทรและชื่อส่วนตัวลูกค้า 100%)
- เมื่อเพิ่มข้อมูลลง `bcbrain/vault/` เรียบร้อยแล้ว ระบบจะย้ายรายการนั้นจาก `[ ]` เป็น `[x]` ไปไว้ในหัวข้อ **3. เพิ่มเข้าคลังความรู้เรียบร้อยแล้ว (Archive)**
- **อย่าใส่เบอร์โทรจริง ชื่อส่วนตัวลูกค้า อีเมล หรือ Public IP** ลงในไฟล์นี้
